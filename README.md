# Phạm Thị Thùy Trang · Portfolio

A Little Prince themed personal portfolio. Open `index.html`; `music.mp3` must stay in the same folder.

## Publish with GitHub Pages
1. Create a new public repository (e.g. `portfolio`).
2. Upload `index.html`, `music.mp3` and `README.md` to the repository root.
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-username>.github.io/portfolio/`.
